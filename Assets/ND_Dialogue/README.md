# ND Dialogue (`Assets/ND_Dialogue`)

Node-based dialogue: database and graph editor, runner, conditions and actions, routers (random, weighted, cycle,
shuffle, utility), barks, sequencer, typewriter text with markup, voices (AudioClip or FMOD), saves, test chat,
Twine / Arcweave import and an AI bridge.

## Needs
The plugins `ND_Core`, `ND_Localization`, `ND_Quests`, `ND_GraphUI`, and Unity UI (TextMeshPro).

## Optional integrations
| Integration | Turns on when | Folder |
|---|---|---|
| ND Behavior Tree (blackboard world, Bark node) | by itself when the ND Behavior Tree plugin is in the project (`ND_DIALOGUE_NDBT`) | `Integrations/NDBT` |
| FMOD voices | FMOD for Unity 2.02+ is imported **and** Project Settings → ND Dialogue → "Use FMOD for voices" is on (`ND_DIALOGUE_FMOD`) | `Integrations/FMOD` |

See `ND_Core/README.md` for how the gate works.
